# Skyline Scheduler

## Vercel'e yükleme

1. Bu klasörü GitHub'a yükle.
2. Vercel.com'a giriş yap.
3. Add New Project / Import Git Repository seç.
4. Bu repository'yi seç.
5. Framework otomatik Vite olarak gelir.
6. Build Command: `npm run build`
7. Output Directory: `dist`
8. Deploy butonuna bas.

## iPhone / iPad kullanımı

1. Vercel linkini Safari'de aç.
2. Share butonuna bas.
3. Add to Home Screen seç.
4. Skyline Scheduler adıyla ana ekrana ekle.

## Not

Backup butonu JSON yedek indirir. Weekly Summary JPEG/Share butonları WhatsApp için kullanılabilir.
